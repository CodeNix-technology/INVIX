# Invix Wiki

Welcome to the **Invix** wiki — the official documentation for Invix, an open-source, local-first invoice generator.

> **Invix — Smart Invoices, Made Simple**

## What is Invix?

Invix is a production-quality invoice web app built with **React + Vite + Tailwind CSS**. It helps freelancers, agencies, and small businesses create professional invoices with:

- 15 professional templates
- Full customization studio
- GST/UPI support
- PDF/PNG/print export
- Optional Supabase cloud sync
- Offline-first/local workspace mode (no login required)
